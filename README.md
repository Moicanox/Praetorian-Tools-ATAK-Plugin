# Praetorian Tools — ATAK Plugin

**Praetorian Tools** is an extension for **ATAK-CIV** designed to provide additional operational tools for tactical users.

The plugin currently includes tools for **logistics reporting** and **ATP formatted tactical messaging**, with interoperability support for **Praetorian C2 Vehicle**.

---

## Overview

Praetorian Tools extends ATAK with additional functions designed for tactical and operational environments.

The project focuses on:

- Simple operator workflows
- Tactical information exchange
- Logistics reporting
- Structured formatted messages
- Interoperability with Praetorian C2 Vehicle
- Future expansion with additional ATAK tools

---

## Current Tools

### TAK Logistic

TAK Logistic provides a dedicated interface for creating and managing logistics-related information directly within ATAK.

It is designed to simplify the preparation and exchange of logistics reports during tactical and operational activities.

---

### Format Messages

Format Messages allows the operator to create structured **ATP formatted messages** directly from ATAK.

The tool provides standardized message composition and is designed for interoperability with **Praetorian C2 Vehicle**.

## Compatibility

Praetorian Tools is developed for:

- **Platform:** Android
- **Application:** ATAK-CIV
- **Tested version:** ATAK-CIV 5.7
- **Plugin:** Praetorian Tools

Compatibility with other ATAK versions may depend on the specific plugin release.

Always check the release notes before installation.

---

## Download

Official compiled APK releases are available from the **Releases** section of this repository.

Go to:

**GitHub → Releases → Latest Release**

Download only APK files distributed through the official Praetorian Tools repository or other official distribution channels.

No source code is distributed through this repository.

---

## Installation

1. Download the compatible Praetorian Tools APK from the official release.
2. Transfer the APK to the Android device running ATAK-CIV.
3. Install the APK.
4. Start ATAK-CIV.
5. Enable or load Praetorian Tools when required by ATAK.
6. Verify that the plugin version is compatible with the installed ATAK-CIV version.

---

## Praetorian C2 Vehicle Integration

Some Praetorian Tools functions are designed to interoperate with **Praetorian C2 Vehicle**.

Praetorian Tools can also be used independently where supported by the individual tool.
